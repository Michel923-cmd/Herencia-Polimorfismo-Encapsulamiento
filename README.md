# Herencia-Polimorfismo-Encapsulamiento
Actividad de Programación Orientada a Objetos en JavaScript

## Descripción
Este proyecto fue realizado para la actividad de Programación Orientada a Objetos del SENA.
En este proyecto se aplican los conceptos de herencia, polimorfismo y encapsulamiento utilizando JavaScript.

## Conceptos utilizados

### Herencia
Se utiliza una clase padre llamada `Vehiculo` y dos clases hijas llamadas `Carro` y `Motocicleta`.

### Polimorfismo
Se utiliza el método `moverse()`, que tiene un comportamiento diferente en la clase `Carro` y en la clase `Motocicleta`.

### Encapsulamiento
Se utiliza la propiedad privada `#kilometraje` para proteger el kilometraje del vehículo.
El kilometraje se puede consultar y modificar mediante métodos.

## Tecnologías utilizadas
- JavaScript
- Programación Orientada a Objetos
